# Red-team #2 (after epics 4–8), 2026-11-20

A separate Opus subagent with no access to the implementation (README and docs/ only; no source, tests or git history) attacked the running fixture bridge over real HTTPS. Target: `cmd/eidbridge/redteam_harness_test.go` (build tag `redteam`) – the real wiring in demo mode with smartid, smartid-v2, mobileid, webeid and eudi on fixture upstreams and the signing relay enabled, plus a device oracle that played the user's ID card (Web eID tokens) and wallet (EUDI presentations). Production-mode attacks used the tester's own builds of the binary. Raw scripts and outputs stayed in the tester's scratch directory (`/tmp/rt/rt2/`, not committed).

Caveat reported by the tester: while it ran, hand-applied mutation tests briefly edited files in `internal/smartid`, so its own builds (attacks 10, 11 on its instance, part of 12) may have compiled a transient mutant. The main target was built before that.
