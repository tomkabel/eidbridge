# Red-team #1 (after INTEGRATION), 2026-11-20

A separate Opus subagent with no access to the implementation (only the README and the data-flow document) attacked two running fixture bridges over real HTTPS: A (manual approval) and B (auto approval), plus a production configuration matrix. The run paused on a rate limit and was resumed from the same binary.

| # | Attack | Verdict |
|---|---|---|
| 1 | Code replay, failed exchange then retry, revocation on replay, cross-client code, 8 concurrent redeems | PASS |
| 2 | PKCE downgrade (plain, missing, wrong-case method, bad lengths, out-of-range verifiers with matching hash) | PASS |
| 3 | redirect_uri manipulation (30 variants, error combinations, cross-client, POST) | PASS |
| 4 | Omitted or malformed state/nonce, repeated parameters, request, request_uri, claims, prompt=none | PASS |
| 5 | QR/session relay to another browser, continue replay | PASS |

| 6b | Callback before poll ordering | INCONCLUSIVE (could not force it) |

| 8a | Production refuses demo settings | FAIL F1, F2 (about 40 other cases PASS) |
| 8b | Demo tokens marked (acr, eid_env, issuer, kid) | PASS |
| 9 | 10,001 pending flows: 10,000 accepted, #10,001 and #10,002 got 503 Retry-After 5, /readyz stayed 200, no victim flow evicted, full login after recovery | PASS |

## Observations

- O1 callback with right cookie but tampered `value` shows restart and keeps the flow pending (state table says failed). Not exploitable; kept, documented.
- O2 `/start` takes the first of repeated fields, limited to enabled values. Kept.
- O3 `/continue` after the 60 s code lifetime redirects with a dead code instead of `access_denied`. Fixed (TestContinueAfterCodeExpirySendsAccessDenied).
- O4 cross-client redeem error said the code was issued to another client. Fixed: same answer as an unknown code (TestCrossClientRedeemErrorIsGeneric).
- O5 any failed first exchange consumes the code (by design, RFC 9700).
- O6 `bearer` in lower case rejected. Fixed: scheme is case-insensitive, RFC 9110 §11.1 (TestUserinfoBearerSchemeCaseInsensitive).
- O7 demo-only settings ignored in production. Kept.
- O8 relabelled demo key accepted unless on the deny-list. By design (ADR 0002 key manifest); documented in docs/security.md.
- O9 `prompt=consent` accepted. The bridge has no consent screen; kept and noted.
