This document helps the people who build and maintain eidbridge see which architecture decisions, guardrails and gates bind the first Smart-ID-to-OIDC bridge release, and which ones are deferred.

**Style and voice to keep:** the text is terse, imperative and normative, with dense technical jargon and many fragment-style specification lines (for example, "Authorization code only, PKCE S256, …"). That compression is deliberate, so the fixes below target only text that is ambiguous, misparses or conflicts with the Microsoft Writing Style Guide. The structure pass ran first but no structure model was supplied to this pass. Its recommendations already cover the glossary and acronym expansion, the issue links and the shape changes. The ADJ section, the ADR-005 operator-docs and production-checklist paragraphs, the ADR-001 Web eID sentence, the planning-task notes, the ADR-002 lifecycle paragraph, the layout path list, the per-release table sentence and the ADR-006 wallet binding list are skipped here. Fixes to the closing caveat are attached to its new location in Status.
